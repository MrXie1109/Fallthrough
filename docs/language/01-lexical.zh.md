# 01 词法

> [English](01-lexical.md)

## 范围

本篇规定源文本如何被切分为记号，以及注释、标识符、关键字、字面量与运算符的词法
形式。记号如何组合成语法结构见后续各篇。

## 源文本

2.1 源文件**必须**以 UTF-8 编码。实现不得接受非法 UTF-8 序列。

2.2 空白（空格、制表符、换行、回车）在词法分析中分隔记号，不构成语法结构。

2.3 注释与空白统称 trivia。实现**应**在记号流中保留 trivia 及其源位置，以支持
源文本的完整重建；保留与否不影响程序语义。

## 注释

3.1 行注释以 `//` 开始，到行尾结束。

3.2 块注释以 `/*` 开始，到其后的第一个 `*/` 结束。块注释**不得**嵌套：第一个
`*/` 终止注释，其余 `*/` 是语法错误。

3.3 注释是 trivia，不参与语法分析与语义分析。

## 标识符

4.1 标识符**必须**以 XID_Start 类字符或 `_` 开始，其后为 XID_Continue 类字符、
数字或 `_`。

4.2 标识符区分大小写。

4.3 实现**不得**对标识符作 Unicode 规范化：码位序列不同的两个标识符是不同名字。

4.4 `_` 是合法标识符，但具有特殊的重复声明规则，见 [09 作用域](10-scopes.zh.md#_)。

## 关键字

5.1 下列词是保留字，**不得**用作标识符：

```text
alignof  as       auto     break    case     const    continue default
defer    define   delete   else     enum     except   export   fallthrough
false    finally  fn       for      from     if       import   interface
lambda   link     mutable  nullptr  raise    return   sizeof   static_assert
switch   template this     traits   true     try      type     union
volatile while
```

5.2 5.1 的清单是完整集合：除此以外的词都不是保留字，程序可以用其中任何一个作标识符。
特别是 `alignas`、`constexpr`、`dynamic`、`extern`、`static`、`thread_local` 都是普通
标识符。它们所描述的声明由属性表达，属性中 `@` 之后的词按普通单词读取而非关键字；
见 [03 声明 §9](03-declarations.zh.md#属性)。

5.3 `export` **是**保留字：它引导一个可被导入者看见的声明，写在属性表之前而不是作为
属性，见 [03 声明 §9](03-declarations.zh.md#属性)与
[08 模块](09-modules.zh.md#导出表)。

5.4 `delete` 保留给将来的删除表达式，目前没有含义。`define` 引导逻辑行起始处的宏定义；
它被保留，是为了让定义始终就是它写的样子——只靠读标识符来识别它的预处理器，会让程序
遮蔽掉那个标识符。

5.5 `@` 之后的属性名不是关键字：它按普通单词读取，合法属性及其位置见
[03 声明 §9](03-declarations.zh.md#属性)。

## 字面量

### 一般规则

6.1.1 字面量是具有类型的记号。整数与浮点字面量的类型可以由上下文决定；当上下文
要求一个类型时，字面量取该类型（见 [02 类型](02-types.zh.md)）。

6.1.2 数字之间的 `_` 是分隔符，不改变数值。

6.1.3 整数后缀写出类型本身，不是转换：`42u8` 的类型是 `u8`。把该字面量用于另一
类型的位置是类型错误，而不是隐式转换。

### 整数字面量

| 形式 | 类型 |
| ---- | ---- |
| `42`、`0x2A`、`0o52`、`0b101010` | 由上下文决定；无上下文时为 `int` |
| `42u8`、`42usize`、`42i64` 等 | 后缀所写的整数类型 |

6.2.1 整数前缀 `0x`、`0o`、`0b` 分别表示十六、八、二进制；不带前缀为十进制。

### 浮点字面量

| 形式 | 类型 |
| ---- | ---- |
| `1.5` | `double`（即 `f64`） |
| `1.5f` | `float`（即 `f32`） |

### 字符字面量

6.4.1 `'x'` 的类型是 `c8`；宽度前缀 `u16'x'`、`u32'x'` 给出更宽的字符类型。

6.4.2 字符字面量只含一个字符（或一个转义序列）。

### 字符串字面量

| 形式 | 类型 | 终止符 | 说明 |
| ---- | ---- | ------ | ---- |
| `"text"` | `[N]const c8` | 有 | 解释转义；UTF-8 存储 |
| `"""text"""` | `[N]const c8` | 有 | 可跨行；解释转义；不裁剪缩进 |
| `u16"text"`、`u32"text"` | `[N]const c16` / `[N]const c32` | 有 | 元素宽度由前缀决定 |
| `b"bytes"` | `[N]const byte` | 无 | 元素类型为 `byte` |
| `r"text"` | `[N]const c8` | 有 | 原始字符串，不解释转义 |
| `r#tag"text"tag#` | `[N]const c8` | 有 | 带定界符的原始字符串 |
| `f"文本{表达式}文本"` | — | — | 插值字符串；本身不是值（6.5.5） |

6.5.1 `N` 是数组元素个数：对 `c8`/`c16`/`c32` 形式，N 等于解码后的元素个数加一
（含终止符）；对 `b` 形式，N 等于字节数（无终止符）。

6.5.2 多行字符串以三个引号开合，可以跨行；单个 `"` 是内容，`\"""` 是转义的引号，
不构成闭合。多行字符串解释转义，并不裁剪行首空白。

6.5.3 原始字符串不解释转义，内容逐字保留。原始字符串的定界符形式为
`r#TAG"…"TAG#`：`TAG` 不得含空白与 `"`，长度不得超过 64 字节；闭合处必须重复
同一 `TAG`。`r` 之后既不是 `"` 也不是 `#…"` 时，`r` 是标识符。

6.5.4 `u16`/`u32` 前缀选择元素类型；`b` 前缀选择 `byte` 元素类型。`b` 形式表示
原始内存，不含终止符。

6.5.5 插值字符串写作 `f"…"`：`f` 是前缀，其后内容按普通字符串读到收尾的 `"`，转义同样适用。
它**不是**数组类型的字面量：它表示一次调用，由
[07 表达式](08-expressions.zh.md#插值字符串)说明该调用是什么。插值字符串可以像 `"…"` 一样
跨行，因为其中的换行就是普通字符。没有 `f"""…"""` 形式。

### 布尔字面量与空指针

6.6.1 `true`、`false` 的类型是 `bool`。

6.6.2 `nullptr` 没有固定的指针类型；它取使用位置要求的指针类型。

### 范围字面量

6.6.3 `low .. high` 与 `low ..= high` 表示一个范围：从 `low` 开始、每次加一的整数序列。
步长为 1，元素类型为 `i64`。

6.6.4 不带 `=` 的形式不含 `high`，带 `=` 的形式含 `high`：`1 .. 5` 走 1、2、3、4，
而 `1 ..= 5` 走 1、2、3、4、5。

6.6.5 两端是表达式而非必须是字面量；每一端**必须**是整数类型或可推断为整数类型。
`1 .. n + 1` 是从 1 到 `n` 的范围，因为范围比任何二元运算符结合得都松。

6.6.6 范围字面量就是标准库的 `Range`：`1 .. 10` 即 `std.range.Range(1, 10, 1)`，
`1 ..= 10` 即 `std.range.Range(1, 11, 1)`。因此它**需要** `import std;` 或
`import std.range;`，可以存入 `Range`、用作范围循环的主体（见
[05 语句](06-statements.zh.md#范围循环)），或传给任何期待 `Range` 的位置。

6.6.7 范围**不得**连写：`1 .. 2 .. 3` 不符合本规范。

下列程序先输出 `1 2 3 4`，再输出 `1 2 3 4 5`：

```ft
import C;
import std;

fn main() int except {
    for (i i64 : 1 .. 5) { C.printf("%ld ", i); }
    C.printf("| ");
    for (i i64 : 1 ..= 5) { C.printf("%ld ", i); }
    C.printf("\n");
    return 0;
}
```

### 转义序列

6.7.1 字符与字符串字面量支持下列转义：`\n`、`\t`、`\r`、`\\`、`\'`、`\"`、`\0`、
`\xNN`、`\u{…}`。

6.7.2 `\u{…}` 的内容是 1 至 6 位十六进制数字，表示一个 Unicode 码位。不带花括号
的 `\u` 不是转义：`\u0041` 是六个字符。

6.7.3 其他转义序列是语法错误，实现**必须**报告诊断。

## 运算符与优先级

7.1 二元与一元运算符的优先级从紧到松如下。结合性由表规定；同级运算符按表列结合
性结合。

| 级别 | 运算符 | 结合性 |
| ---- | ------ | ------ |
| 13 | 前缀 `+ - ! ~ &`、`*`（解引用）、`++`、`--` | 右 |
| 12 | `as` | 左 |
| 11 | `**` | 右 |
| 10 | `* / %` | 左 |
| 9 | `+ -` | 左 |
| 8 | `<< >>` | 左 |
| 7 | `< <= > >= <=>` | 左 |
| 6 | `== !=` | 左 |
| 5 | `&` | 左 |
| 4 | `^` | 左 |
| 3 | `\|` | 左 |
| 2 | `&&` | 左 |
| 1 | `\|\|` | 左 |
| 0 | `?:`、`=` 与复合赋值 | 右 |
| — | `..`、`..=`（比上面每个运算符都松） | — |

7.1.1 范围不是作用于两个值的运算符：它的两端是整数，整体是一个 `Range`。因此它位于
`?:` 之下，并把每一端当作完整表达式，所以 `1 .. n + 1` 是从 1 到 `n + 1` 的范围。

7.2 后缀形式（调用、下标、成员访问、`++`、`--`、`??`、`!!`）的优先级高于表中任何二元
运算符。

7.3 `as` 的优先级高于任何二元运算符、低于前缀运算符：`-x as u8` 等价于
`(-x) as u8`，`x as u8 == 7` 等价于 `(x as u8) == 7`。

7.4 `**` 为右结合：`2 ** 3 ** 2` 等价于 `2 ** (3 ** 2)`。

7.5 位运算的优先级低于比较运算；这与 C 一致。

## 宏与属性记号

8.1 `$` 引导宏调用：`$NAME` 或 `$NAME(args)`，见 [03 声明](03-declarations.zh.md#宏)。

8.2 `@` 引导属性：`@name` 或 `@name(args)`，见
[03 声明](03-declarations.zh.md#属性)。

8.3 `#` 作为记号仅在宏体中具有含义：`#param` 把实参转为字符串字面量，
`a ## b` 把两个记号拼接为一个。原始字符串中的 `#` 属于字面量。

## 记号切分的特殊规定

9.1 `.{` 是**一个**记号，用于指定初始化器。要得到 `.` 与 `{` 两个记号，必须写成
`. {`。

9.2 `->` 是指针成员访问记号；在 `traits` 与 `interface` 的要求中它同时表示结果
类型，见 [03 声明](03-declarations.zh.md#traits)。

9.3 在模板实参列表中，`>` 与 `>>` 按需要拆分：`Array<Array<int>>` 中的 `>>`
切分为两个 `>`。

9.4 记号之间以空白或 trivia 分隔；相邻的运算符按最长匹配切分，表 7.1 未列出的
组合可能构成单个记号（例如 `->`、`++`），其含义由语法规定。
