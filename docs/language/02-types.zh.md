# 02 类型

> [English](02-types.md)

## 范围

本篇规定类型系统：类型的分类、书写形式、布局与对齐、类型等价，以及语言允许的
隐式类型调整。类型语法出现在所有声明位置；声明本身的形式见
[03 声明](03-declarations.zh.md)。

## 类型语法

2.1 类型写在被声明名字之后：`x int` 声明名为 `x` 的 `int`。该顺序适用于绑定、形参、
返回类型、字段、模板参数、常量与 trait 参数。

2.2 类型语法由下列构成：

| 形式 | 含义 |
| ---- | ---- |
| 内建类型名 | 见第 3 节 |
| `*T`、`*const T`、`const *T` | 指针 |
| `&T`、`&const T`、`&&T`、`&&const T` | 引用 |
| `[N]T`、`[]T` | 数组 |
| `fn(Ps) R`、`fn "ABI" (Ps) R`、`fn(Ps) R except` | 函数类型 |
| `*fn(...)...` | 函数指针 |
| `Name`、`Outer.Name`、`Family<Args>` | 名义类型 |
| `type(expr)` | 表达式类型 |
| `?T` | 可选值语法糖 |
| `auto`、`type(auto)` | 仅用于可推断类型的声明与返回类型 |

2.3 限定词 `const`、`volatile` 写在类型之前，并约束其后的那一层间接。声明修饰符
（如 `@static`、`@align(..)`）作为属性写在声明之后，见
[03 声明](03-declarations.zh.md#声明修饰符)。

## 基本类型

| 名字 | 规定 |
| ---- | ---- |
| `i8`、`i16`、`i32`、`i64`、`i128` | 有符号整数，宽度分别固定 |
| `u8`、`u16`、`u32`、`u64`、`u128` | 无符号整数，宽度分别固定 |
| `int`、`uint` | 分别与 `i32`、`u32` 同宽 |
| `isize`、`usize` | 指针宽度；长度、下标与 `sizeof` 的结果类型为 `usize` |
| `byte` | 8 位原始内存单元；**不是** `u8` 的别名 |
| `bool` | 布尔类型 |
| `c8`、`c16`、`c32` | 字符类型；`char` 等价于 `c8` |
| `f32`、`float` | 单精度浮点 |
| `f64`、`double` | 双精度浮点 |
| `void` | 无值类型；仅用作返回类型 |

3.1 `byte` 不参与算术运算，也不与 `u8` 隐式互转；两者之间的转换**必须**写 `as`。

3.2 字符类型不参与算术运算；按码位运算时**必须**显式转换为整数类型。

3.3 有符号整数的表示是实现定义的，但本实现采用二补码。整数溢出在默认模式下
**必须**产生诊断或受控失败，`--release` 模式下为未定义行为。

## 函数类型

### 形式

| 写法 | 含义 |
| ---- | ---- |
| `fn(int) int` | 接收 `int`、返回 `int` 的函数类型 |
| `*fn(int) int` | 指向该函数类型的指针 |
| `fn(int) int except` | 可能抛出的函数类型 |
| `fn "C" (int) int` | 使用 C ABI 的函数类型 |

4.1.1 函数类型由形参类型序列、返回类型、调用约定与“是否可能抛出”组成。

4.1.2 `except` 是函数类型的一部分。可能抛出的函数类型与不抛出的函数类型互不
兼容，两个方向都**不得**隐式转换。

4.1.3 通过函数指针调用与直接调用具有相同的调用点义务（见
[06 异常](06-exceptions.zh.md)）。

### 函数名到指针的转换

4.2.1 在要求函数指针的位置，函数名**调整**为指向该函数的指针；`&f` 产生同一
指针。

4.2.2 重载的函数名由目标函数类型选出唯一的重载。无法唯一确定时，程序不符合
本规范。

4.2.3 函数指针按函数调用的语法调用：`p(1)`；`(*p)(1)` 不是本规范允许的写法。

## 指针

### 形式与含义

| 写法 | 含义 |
| ---- | ---- |
| `*T` | 指向可写 `T` 的指针 |
| `*const T` | 指向只读 `T` 的指针 |
| `const *T` | 指针本身为只读；可以写指向的对象 |

5.1.1 限定词约束其后的那一层：`*const T` 约束指向对象，`const *T` 约束指针本身。

5.1.2 `&x` 产生**指针**，类型为 `*T`，不是引用。取地址的操作数**必须**是地方。

### 指针算术

指针算术以元素为单位，由实现按被指向类型的大小缩放。

| 写法 | 偏移类型 | 结果 |
| ---- | -------- | ---- |
| `p + n`、`n + p` | `usize` | 与 `p` 同类型的指针，向后 `n` 个元素 |
| `p - n` | `usize` | 与 `p` 同类型的指针，向前 `n` 个元素 |
| `p - q`（被指向类型相同） | — | `isize`，元素个数差 |
| `p += n`、`p -= n` | `usize` | 赋值形式 |
| `++p`、`p++`、`--p`、`p--` | — | 移动一个元素 |
| `p[i]` | `usize` | 等价于 `*(p + i)` |

5.2.1 偏移量的类型**必须**是 `usize`。无后缀整数字面量取 `usize`；其他整数类型
**必须**显式转换。

5.2.2 指针算术的结果保持原指针的限定词。

5.2.3 指针算术**不检查越界**：指向数组内任一元素，或指向末元素之后一个位置，
是合法的；此外的行为是未定义行为。该规则与优化级别无关。

## 引用

### 形式与产生

| 写法 | 含义 |
| ---- | ---- |
| `&T` | 引用；该名字命名一块存储 |
| `&const T` | 只读引用 |
| `&&T` | 右值引用；绑定将死的值 |
| `&&const T` | 只读右值引用 |

6.1.1 引用只出现在类型位置。语言**没有**产生引用的运算符。

6.1.2 `*p`（`p` 为 `*T`）的类型是 `&T`：解引用得到被指向的存储本身，不是副本。

6.1.3 源码中的 `&&` 只有一种含义：右值引用。引用折叠只发生在推导出的类型上
（模板实参、`type(expr)` 的结果）：两个引用叠加时取其中一个。

6.1.4 `*` **不得**作用于引用：引用本身命名值，直接使用该表达式即可。

6.1.5 类型为 `&T` 的表达式在要求值的位置读作 `T`。该规则使返回引用的
`__deref__`、`__getitem__` 可以用于读取与赋值。

6.1.6 形参位置的隐式取地址：类型 `T` 的值可以满足 `&T`、`&const T` 形参。该调整
**仅**在形参位置成立。

6.1.7 右值引用只绑定将死的值；左值绑定到右值引用是错误。

## 数组

### 形式

| 写法 | 含义 |
| ---- | ---- |
| `[N]T` | `N` 个 `T`，连续存放；`N` 是常量表达式 |
| `[]T` | 长度未知；作为形参类型时等价于 `*T` |
| `[N]const T` | 元素只读 |

7.1.1 数组元素内联于数组对象，无间接层。

7.1.2 在实参位置，数组**调整**为指向首元素的指针 `*T`。

7.1.3 数组**不得**按值返回。函数返回类型为数组形式时，实现**必须**报告诊断。

### 下标

7.2.1 对 `[N]T` 与 `*T`，下标类型**必须**是 `usize`；越界是未定义行为。

7.2.2 名义类型可以声明 `__getitem__` 自行规定下标类型与越界行为，见
[07 表达式](07-expressions.zh.md#特殊方法)。

7.2.3 语言没有切片类型，也没有元组类型。`[]T` 仅是形参写法；多个值由名义类型
承载。

## 名义类型

### 声明形式

```ft
type Point {
    x int;
    y int;
}

union Value {
    i int;
    b byte;
}

enum Color int {
    RED,
    GREEN = 5,
    BLUE,
}

type Id = usize;
```

8.1.1 `type Name { … }` 声明结构体：字段按书写顺序排列。

8.1.2 `union Name { … }` 声明联合体：字段共享起始地址，宽度为最大成员宽度；
活动成员由程序保证。读取非活动成员是未定义行为。

8.1.3 `enum Name Base { … }` 声明枚举：成员是类型为 `Base` 的具名常量；`Base`
**必须**是整数类型，省略时为 `int`。未写值的成员等于前一成员的值加一，首个成员
为 0。

8.1.4 `type Name = Other;` 声明别名：不引入新类型，两个名字指同一类型。

### 自引用

8.2.1 一个类型**不得**按值包含自身。通过指针或引用提及自身是允许的。

8.2.2 不完整类型只能用于指针、引用与声明；按值定义、`sizeof`、访问成员与按值
传参**必须**要求完整类型（见 [03 声明](03-declarations.zh.md#前置声明)）。

### 嵌套类型

8.3.1 名义类型体内可以声明属于该类型的别名，以 `Outer.Name` 命名。

8.3.2 嵌套类型不是字段：不占存储，不参与初始化。

8.3.3 对类型族，嵌套类型属于**实例**：`Cell<int>.Element` 与
`Cell<u8>.Element` 是不同类型。

8.3.4 本规范只允许嵌套**别名**。嵌套的结构体、联合、枚举与模板不在本规范范围
内，实现**必须**报告诊断。

## 布局与对齐

### 布局

9.1.1 名义类型的布局遵循下列规则，与 C 相同：

1. 字段置于其对齐要求的下一个倍数处，必要时插入填充；
2. 整个类型按其最宽字段的对齐补齐。

9.1.2 `sizeof(T)` 是补齐后的字节数；`alignof(T)` 是类型的对齐。

9.1.3 联合体的对齐等于其成员中最大的对齐；`sizeof` 为最大成员宽度补齐后的值。

9.1.4 布局在编译期固定；程序不得依赖本规范未规定的填充字节内容。

### `@align`

9.2.1 字段与变量可以用 `@align(N)` 抬高对齐；`N` **必须**是正的 2 的幂，且是
编译期常量。`@align(T)` 等价于 `@align(alignof(T))`。

9.2.2 `@align` **只能**抬高对齐；要求低于类型自身对齐的 `@align` 是错误。

9.2.3 抬高的对齐向后续字段传播，并决定整个类型的对齐与 `sizeof`。

## `const` 与 `volatile`

10.1 `const T` 表示只读：不得通过该名字写入。`volatile T` 表示每次访问都必须
真实发生。两者可组合。

10.2 `const` 是浅的：只约束写操作所经过的那一层，不传播到被指向或引用的对象。

10.3 `const` 对象**不得**调用接收者为 `this &T` 的成员函数；接收者为
`this &const T` 的成员函数可以调用。`mutable` 字段是唯一例外。

## 类型等价

11.1 下列类型对**等价**：`int` 与 `i32`；`uint` 与 `u32`；`char` 与 `c8`；
`float` 与 `f32`；`double` 与 `f64`；别名与其命名的类型。

11.2 `const T` 与 `T` 在类型等价上相同，仅在可写性约束上不同；`*T` 与
`*const T` 是不同类型。

11.3 两个不同翻译单元中的同名名义类型，若来自同一模块声明，则是同一类型；若
分别声明，则是不同类型。

## 类型转换与隐式调整

12.1 语言**没有**一般意义上的隐式数值转换。数值类型之间的转换**必须**写 `as`，
唯一例外是第 12.5 条规定的**整数提升**。

12.2 下列**隐式调整**是本规范允许的全部隐式类型变化；除此之外不得发生隐式
类型变化：

| 调整 | 位置 |
| ---- | ---- |
| 真值测试 | 条件位置 |
| 数组退化为指向首元素的指针 | 表达式与实参位置 |
| 函数名退化为函数指针 | 要求函数指针的位置 |
| 值的地址传给引用形参 | 形参位置 |
| 增加 `const` 限定 | 指针、引用与对象 |
| 指针与同形状引用互相兼容 | 指针/引用形参位置 |
| `*T` 与 `*byte` 互相转换 | 指针位置 |
| 值装箱为它满足的 `interface` | 初始化与赋值 |
| 字面量取上下文要求的类型 | 字面量位置 |
| 整数提升（见 12.5） | 要求目标整数类型的位置 |
| 目标类型的 `__im_init__` | 要求目标类型的位置（见 [07 表达式](07-expressions.zh.md#隐式初始化与隐式转换)） |
| 源类型的 `__im_as__` | 要求目标类型的位置（见 [07 表达式](07-expressions.zh.md#隐式初始化与隐式转换)） |
| 可选值语法 `?T` 展开为库类型 | 类型位置 |

12.3 减少 `const` **必须**写 `as`。

12.4 有损数值转换按目标宽度回绕，这是转换本身的语义，不是错误。

### 整数提升

12.5 整数提升是一种**无损**的隐式整数转换：源整数类型的全部取值都落在目标整数
类型的取值范围内时，允许隐式提升。

12.5.1 参与整数提升的类型**必须**是整数类型：`i8`、`i16`、`i32`、`i64`、`i128`、
`u8`、`u16`、`u32`、`u64`、`u128`、`int`、`uint`、`isize`、`usize`。下列类型
**不参与**整数提升，既不得作为源类型，也不得作为目标类型：

- `bool`；
- 字符类型 `c8`、`c16`、`c32`；
- `byte`；
- 枚举与其他名义类型。

12.5.2 记源类型为 `S`、目标类型为 `T`，`width(X)` 为类型的位宽。仅当下列条件
之一成立时，`S` 的值可以隐式提升到 `T`：

| 条件 | 例子 |
| ---- | ---- |
| `S` 与 `T` 均为无符号，且 `width(S) <= width(T)` | `u8` → `u16`、`u32` → `u64` |
| `S` 与 `T` 均为有符号，且 `width(S) <= width(T)` | `i8` → `i16`、`i32` → `isize` |
| `S` 为无符号、`T` 为有符号，且 `width(S) < width(T)` | `u8` → `i16`、`u32` → `i64` |

12.5.3 **有符号整数不得隐式转换为无符号整数**：`i8` → `u8`、`i32` → `u64` 等都
必须写 `as`。这是 12.5.2 的自然结果（负值不在目标值域内），此处单独规定，因为它
是最容易误用的一种。

12.5.4 不满足 12.5.2 的整数转换（同宽符号不同、窄化、有符号转无符号）**必须**
写 `as`。显式 `as` 允许任意数值方向，其截断与回绕语义见 12.4。

12.5.5 整数提升适用于要求目标整数类型的位置：绑定初始化、赋值、实参绑定、
返回值、字段初始化器与构造实参。提升不改变运算符的选择：算术与位运算的操作数
**不得**借整数提升变得类型不同，仍须类型一致或显式 `as`。比较运算的规则见
[07 表达式](07-expressions.zh.md)，不受本条影响。

12.5.6 无后缀整数字面量取上下文要求的类型，这属于字面量的类型选定，不是整数
提升。

## `type(expr)`

13.1 `type(expr)` 产生类型，只能出现在类型位置。

13.2 当操作数是裸名字或成员访问时，结果是该**实体**声明的类型。

13.3 否则结果为**表达式**的类型：命名存储的表达式给出 `&T`，其余给出 `T`。

13.4 引用折叠适用。

13.5 操作数不被求值，但会被检查；其中的错误**必须**报告。

13.6 字段声明**不得**使用 `type(expr)`：布局在任何表达式被检查之前已经确定。

## 可选值

14.1 `?T` 是类型语法糖，等价于标准库的 `Optional<T>`。该语法本身属于本规范；
`Optional<T>` 的行为由标准库规定。

14.2 使用 `?T` 时，程序**必须**能够导入声明 `Optional<T>` 的模块。
