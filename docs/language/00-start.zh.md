# 00 总则

> [English](00-start.md)

## 范围

本篇规定翻译单元与程序的组成、程序入口的形式、编译产物的接口，以及实现所报告
诊断的消费方式。语言构造的语义见后续各篇。

## 源文件、翻译单元与模块

2.1 源文件以扩展名区分用途：

| 扩展名 | 用途 |
| ------ | ---- |
| `.ft` | 翻译单元；可以单独编译为程序，也可以与其他 `.ft` 文件共同构成程序 |
| `.ftm` | 模块；只能通过 `import` 被使用，不得单独编译为可执行程序 |

2.2 一个 `.ft` 文件**不得**被 `import`；实现必须拒绝这种导入并给出诊断。

2.3 模块名由 `.ftm` 文件的路径确定：去掉扩展名后，目录分隔符写作 `.`。
`std.string` 对应 `std/string.ftm`。模块名的解析规则见 [08 模块](09-modules.zh.md)。

2.4 一个翻译单元由下列内容构成：该 `.ft` 文件的全部顶层声明，以及它静态导入的
全部模块所导出的声明。

## 程序入口

3.1 程序从名为 `main` 的函数开始执行。`main` 的**形参表必须**为空，或恰为
`argc int, argv **c8`；返回类型**必须**为 `int`、`void`，或在有函数体时省略。

3.2 返回 `int` 时，返回值即程序退出码；返回 `void` 或省略返回类型时，退出码为 0。

3.2.1 返回 `int` 的 `main` 相当于以 `return 0;` 结尾：执行到函数体末尾而没有 `return` 时
返回 0，与 C 程序从 `main` 末尾落出一致。

3.2.2 对其他函数而言，声明了非 `void` 返回值却在函数体末尾落出是未定义行为：函数**应**
在每一条可达路径上都返回。`main` 是语言唯一代为补上该值的地方，因为读者最先遇到的正是
它的函数体。

3.3 `main` 可以声明为可能抛出（`except`）。未捕获的异常由实现报告，报告的格式与
退出码见 [06 异常](07-exceptions.zh.md)。

3.4 形参表或返回类型不符合 3.1 的 `main` 是违反本规范的约束，实现**必须**报告诊断
（`S0181`）。

3.5 形如 `argv **c8` 的参数遵循 C 程序的约定：`argv[0]` 为程序路径，
`argv[argc]` 为空指针。`argv` 不是标准库容器；需要容器时由程序自行构造。

## 编译接口

4.1 实现**必须**提供一种方式，把源文件编译为下列产物之一或其组合：可执行文件、
目标文件、LLVM 汇编、语法树、类型表、记号流。实现**可以**另外提供静态库（程序
目标文件的归档）或共享库。

4.2 实现**必须**支持只做词法、语法与静态语义检查而不产生可执行产物的模式。

4.3 实现**必须**在成功时以退出码 0 结束。下列退出码的含义是规范性的：

| 退出码 | 含义 |
| ------ | ---- |
| 0 | 编译成功 |
| 1 | 程序违反本规范，已报告诊断 |
| 2 | 命令行用法错误 |
| 3 | 实现遇到本规范未规定的构造 |
| 70 | 程序运行结束于未捕获异常（程序的退出码，非实现的退出码） |

4.4 实现的命令行选项拼写不受本规范约束，但其行为不得违反上述约定。

## 编译期限制与实现边界

5.1 实现可以限制资源使用（递归深度、模板实例化次数、诊断数量等）。达到限制时，
实现**必须**报告诊断，**不得**静默接受或产生未定义结果。

5.2 实现遇到 [`../SPEC-STATUS.md`](../SPEC-STATUS.md) 中标为 *Open* 的构造时，
**必须**报告内部错误类诊断 `I0999`。该诊断表示实现未完成，不表示程序有错。

## 实现附带的标准库

6.1 实现附带一个标准库，其模块由 `std` 伞模块或各子模块导入。标准库不属于本
规范的规范性内容；其行为由标准库自身的文档规定。

6.2 标准库的 `std` 伞模块**必须**以重导出方式提供其子模块的导出名；重导出的
语义见 [08 模块](09-modules.zh.md)。

## 遇到错误时

7.1 诊断由实现报告。诊断的文本、编号与位置构成实现对外契约的一部分；编号稳定，
措辞可以随版本变化。

7.2 一条诊断至少包含：严重级别、稳定编号、主位置（源文本范围）、消息。诊断可以
附带补充说明，用于陈述相关规则或修正方式。

```text
error[S0002]: cannot find `printf` in this scope
  --> hello.ft:4:5
   |
 4 |     printf("hi\n");
   |     ^~~~~~
```

7.3 编号由阶段字母与四位数字组成：`D`（驱动）、`L`（词法与宏）、`P`（语法）、
`S`（语义）、`I`（内部错误）。编号的完整含义与警告分组见
[10 诊断](11-diagnostics.zh.md)。

7.4 实现**必须**对同一程序位置上的同一诊断去重；去重规则见
[10 诊断](11-diagnostics.zh.md)。

7.5 程序**不得**依赖诊断文本的具体措辞；程序可以依赖编号与位置。
