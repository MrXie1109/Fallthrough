# 附录 B 特殊方法表

> [English](appendix-b-special-methods.md)

## B.1 范围

本附录汇集语言在固定构造上调用的全部特殊方法：名称、调用时机、签名约定与约束。
条款正文以 [07 表达式 §8](07-expressions.zh.md#特殊方法) 为准；本附录是对照表，不
另行创设规则。

## B.2 一般规则

B.2.1 特殊方法是以 `__name__` 拼写的成员函数，其**第一个形参必须名为 `this`**，
且类型**必须是引用**：`this &T` 或 `this &const T`（[04 函数 §5](04-functions.zh.md#成员函数)）。
指针接收者不符合本规范。

B.2.2 一个特殊方法是否可能抛出（`except`）是它**类型的一部分**；在调用点需要
保护的构造上，它遵守 [06 异常](06-exceptions.zh.md) 的调用点义务。

B.2.3 跨模块使用时，特殊方法**必须**与类型一起 `export`；未导出的方法对导入方
不存在（[08 模块](08-modules.zh.md#导出表)）。

B.2.4 `__init__` 只用于显式构造；`__im_init__` 同时允许隐式初始化。
`__as__` 只用于显式转换；`__im_as__` 同时允许隐式转换。定义 `__im_init__` 也同时
定义了一个 `__init__`，定义 `__im_as__` 也同时定义了一个 `__as__`
（[07 表达式 §8.6](07-expressions.zh.md#隐式初始化与隐式转换)）。

B.2.5 带 `i` 形式的方法（`__iadd__` 等）用于复合赋值；带 `r` 形式的方法（`__radd__`
等）用于左操作数没有对应方法、而右操作数有的二元运算。这两种形式不是独立的表项，
而是基础方法在调用规则上的派生（见 B.6）。

## B.3 构造、赋值与销毁

| 特殊方法 | 调用时机 | 签名约定 |
| -------- | -------- | -------- |
| `__init__` | 显式构造 `T(args)`、`T{…}` 走 `__init__` 时的构造 | 接收者 `this &T`，构造实参随后 |
| `__im_init__` | 构造；并允许在初始化、赋值、实参、返回值、字段等目标类型位置**隐式**完成 | 同 `__init__` |
| `__assign__` | 对已存在的值赋值：`t = v;` | 接收者 `this &T`，源值参数 |
| `__drop__` | 值的作用域结束、被覆盖、`erase`/`pop` 移除 | 接收者 `this &T`，无其他参数 |
| `__getitem__` | `t[i]` | 接收者 `this &T` 或 `this &const T`，下标参数；返回引用时 `t[i] = v` 可写 |
| `__setitem__` | `t[i] = v` 且类型声明了它 | 接收者 `this &T`，下标与值参数 |

B.3.1 没有声明 `__init__`/`__im_init__` 的类型可以用字段初始化器（`T{…}`、`.{…}`）
建立，不经过构造方法。

B.3.2 没有声明 `__drop__` 的类型按其字段的析构规则销毁；拥有资源的类型**应**声明
它。

B.3.3 移动构造是形参为右值引用（`&&T`）的 `__init__`/`__im_init__`；移动赋值是
形参为右值引用的 `__assign__`。

## B.4 转换与文本

| 特殊方法 | 调用时机 | 签名约定 |
| -------- | -------- | -------- |
| `__as__` | 显式转换 `expr as T` | 接收者 `this &const T`（源值），第二个形参为指向目标类型的**选择器**（只用于选择，从不使用） |
| `__im_as__` | 转换；并允许在目标类型位置**隐式**完成 | 同 `__as__` |
| `__str__` | `str(x)` | 接收者 `this &const T`，返回字符串 |
| `__repr__` | `repr(x)` | 同上 |
| `__format__` | 标准库格式化（`std.fmt`） | 接收者 `this &const T`，返回字符串 |
| `__hash__` | 散列（`std.hash` 及其上的容器） | 接收者 `this &const T`，返回 `usize` |

B.4.1 转换不能按返回类型重载，因此目标类型由选择器参数指名：`*double` 选择
`double`（比较时忽略 `const`）。

B.4.2 `str`/`repr` 是内建函数：类型声明了对应方法时调用它，否则实现按值类别
的默认规则渲染（[07 表达式 §8.3](07-expressions.zh.md#str-与-repr)）。

## B.5 运算符

| 特殊方法 | 运算符 | 备注 |
| -------- | ------ | ---- |
| `__add__` `__sub__` `__mul__` `__div__` `__mod__` `__pow__` | `+ - * / % **` | `/` 与 `%` 为截断语义 |
| `__and__` `__or__` `__xor__` `__shl__` `__shr__` | `& \| ^ << >>` | 按位 |
| `__neg__` `__pos__` `__not__` | 一元 `- + !` | 逻辑非 `!` 由 `__not__` 承担；按位取反 `~` 只对整数类型有定义，没有特殊方法 |
| `__iadd__` `__isub__` … | `+= -= …` | 复合赋值；未声明时退化为 `a = a op b` |
| `__eq__` `__ne__` `__lt__` `__le__` `__gt__` `__ge__` | `== != < <= > >=` | 返回类型由方法决定，用作条件时**应**为 `bool` |
| `__cmp__` | `<=>` | 返回负/零/正 |
| `__inc__` `__dec__` | `++a` / `--a` 及后缀形式 | 操作数**必须**是地方 |
| `__deref__` | `*a` | 返回引用 |
| `__pointer__` | `a->field` | 返回下一步要访问的对象，可链式 |
| `__call__` | `a(args)` | |
| `__bool__` | 条件中的 `a` | 结果应为 `bool` |

B.5.1 两个操作数类型不同、或类型是名义类型时，运算落到左操作数的特殊方法；左
操作数没有时尝试右操作数的 `r` 形式（`__radd__` 等）。

B.5.2 两个相同的名义类型不会自动比较或逐成员比较：需要比较时**必须**声明对应
方法。

## B.6 派生形式

| 形式 | 含义 | 何时考虑 |
| ---- | ---- | -------- |
| `__iadd__` 等 | 复合赋值的原地形式 | `+=` 优先于 `a = a + b`；声明它表示"修改自身" |
| `__radd__` 等 | 交换操作数的二元形式 | 左操作数类型没有声明 `__add__` 时 |
| 后缀 `++`/`--` | 修改前的副本 | `__inc__`/`__dec__` 对前缀与后缀同一份实现，语言保存副本 |

B.6.1 复合赋值的结果类型总是目标的类型：`i` 形式返回的值被丢弃，操作被视为对
目标的修改。

## B.7 约束汇总

B.7.1 特殊方法**必须**是成员函数（首位形参 `this`）。

B.7.2 `this` **必须**是引用；不可写接收者用 `this &const T`，可写接收者用
`this &T`。

B.7.3 `__as__`/`__im_as__` **必须**有第二个形参作为目标类型的选择器。

B.7.4 `__inc__`/`__dec__` 与赋值类特殊方法的操作数**必须**是地方。

B.7.5 特殊方法参与重载解析的方式与普通成员函数相同；同一类型可以对不同源类型
声明多个 `__assign__`/`__as__`/`__init__`，由实参选择。

B.7.6 特殊方法的调用可以抛出：声明 `except` 的方法在被隐式调用的构造上同样
产生调用点义务（[06 异常 §7](06-exceptions.zh.md#隐式调用点)）。
