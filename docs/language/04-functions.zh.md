# 04 函数与调用

> [English](04-functions.md)

## 范围

本篇规定函数与成员函数的声明、`lambda` 与闭包、调用时的实参传递、重载选择、
默认实参、返回值推断、移动语义与求值顺序。异常是调用点义务的一部分，见
[06 异常](07-exceptions.zh.md)。

## 函数声明

### 形式

```ft
import C;

fn add(a int, b int) int { return a + b; }
export fn visible(a int) int { return a * 2; }
@constexpr fn square(n int) int { return n * n; }

fn main() int {
    C.printf("%d %d %d\n", add(1, 2), visible(3), square(4));
    return 0;
}
```

该程序输出 `3 6 16`：普通定义、导出定义与 `constexpr` 定义写法相同，调用方式也相同。

2.1.1 有函数体的函数可以省略返回类型：省略等价于 `auto`，由 `return` 语句推断。
不返回值时返回类型为 `void`，也可以省略。

2.1.2 没有函数体的函数**必须**写出返回类型（`void` 也必须写出）。

2.1.3 函数的类型记作 `fn(Ps) R`；函数指针类型记作 `*fn(Ps) R`，见
[02 类型](02-types.zh.md#函数类型)。

2.1.4 `export` 使函数对导入者可见；`@extern_C` 指定 C ABI 且不带函数体；
`constexpr` 承诺函数可用于常量位置。

2.1.5 同一模块内的函数可以互相引用，与书写顺序无关。

2.1.6 可变参数 `...` 仅用于 C 互操作；此类调用中多出的实参不做类型检查。

2.1.7 函数可以用 `except`（及条件）声明可能抛出，见
[06 异常](07-exceptions.zh.md)。

### 默认实参

2.2.1 形参可以带默认值：`fn greet(name *const c8, punct *const c8 = "!") int`。

2.2.2 带默认值的形参**必须**位于不带默认值的形参之后。

2.2.3 默认值是表达式，在调用处求值，且仅在实参被省略时求值。默认值可以使用其
前面的形参。

2.2.4 默认值的类型**必须**与形参类型兼容；检查在声明处进行。

### 关键字实参

2.3.1 调用可以用 `.name = value` 按名字提供实参；关键字实参**必须**位于所有按
位置书写的实参之后。

2.3.2 `.name` **必须**是形参名。成员函数的接收者不能按名字提供。

2.3.3 一个形参**不得**得到两次值：既按位置又按名字提供同一形参是错误。

2.3.4 省略的形参由默认值填充；没有默认值的形参不能被省略。

2.3.5 跨模块调用时，声明模块的默认值记录随导出签名保留（见
[08 模块](09-modules.zh.md#默认值跨模块)）。

## 构造调用

3.1 `T(args)` 是构造调用，选择一个形参表匹配的 `__init__`。

3.2 `T{…}` 与 `.{…}` 是按字段的初始化器，用位置或 `.field = value` 指定字段；
初始化器**不要求** `__init__`。

3.3 两种形式在类型上下文中都可用；`.{…}` 需要上下文提供类型。

3.4 没有匹配的构造函数时是类型错误；实现**应**同时提示初始化器写法。

3.5 显式构造形式 `T(args)` 使用 `__init__` 或 `__im_init__`。当初始化器、赋值、
实参、返回值或字段的值不是目标类型时，只有在目标类型声明了匹配的 `__im_init__`、
或源类型声明了匹配的 `__im_as__` 时，转换才隐式成立；完整规则见
[07 表达式](08-expressions.zh.md#隐式初始化与隐式转换)。

## 实参与形参

### 谁接收引用谁接收指针

4.1.1 `&` 产生指针；引用是类型的写法。

```ft
import C;

type Point {
    x int;
    y int;
}

fn takes_ref(s &const Point) int { return s.x; }
fn takes_ptr(p *Point) int { return p.x; }

fn main() int {
    p Point = .{11, 2};
    C.printf("%d %d\n", takes_ref(&p), takes_ptr(&p));
    return 0;
}
```

该程序输出 `11 11`：引用形参与指针形参都接收地址，并都通过它读到同一个字段。

4.1.2 在形参位置，类型为 `T` 的值可以满足 `&T`、`&const T` 形参：实现把实参的
地址传入。该调整**仅**在形参位置成立。

### 兼容性

4.2.1 实参类型**必须**与形参类型兼容。除 [02 类型](02-types.zh.md) 第 12 节列出的
隐式调整外，不得发生隐式转换。

4.2.2 整数字面量取形参的整数类型。

4.2.3 在形参要求某个声明类型时，字符串字面量可以通过该类型的 `__init__` 构造。

### 按值聚合实参的语义

4.3.1 按值传递的名义类型形参是一个**独立的副本**：形参是调用者实参的副本，
对形参的写入不影响实参。

4.3.2 该副本**必须**按类型自己的拷贝语义建立：类型声明了
`__init__(this &T, other &const T)` 时，实现**必须**调用它；否则按成员逐一复制。

4.3.3 形参在函数返回时**必须**按其类型的析构语义销毁（`__drop__` 或成员析构）。

4.3.4 类型未声明拷贝构造与析构时，实现按成员复制，不产生诊断；此时两个值可能
共享资源，程序自行负责。

## 成员函数

5.1 第一个形参名为 `this` 的函数是成员函数。

5.2 `this` **必须**是引用：`this &T`（可写）或 `this &const T`（只读）。指针接收者
不符合本规范（`S0190`）：

```ft
import C;

type Point {
    x int;
    y int;
}

fn length(this &const Point) int { return this.x + this.y; }
fn shift(this &Point, d int) void { this.x += d; }

fn main() int {
    p Point = .{1, 2};
    C.printf("%d\n", length(&p));
    shift(&p, 10);
    C.printf("%d\n", p.x);
    return 0;
}
```

该程序先输出 `3`，再输出 `11`：`length` 只读接收者、不得写它，而 `shift` 取
`this &Point` 并写入字段。

5.3 调用成员函数时，接收者作为第一个实参传入。接收者为值时，实现取它的地址；
接收者本身就是引用或指针值时，传入它持有的地址。

5.4 通过指针 `p` 调用成员函数时，`p.m()` 等价于 `(*p).m()`。

5.5 `const` 是浅的：`const` 对象不能调用接收者为 `this &T` 的成员函数；可以调用
`this &const T` 的成员函数。`mutable` 字段例外。

## `lambda` 与闭包

6.1 `lambda` 是匿名函数表达式：`lambda(ps) -> expr` 或 `lambda(ps) { … }`。

6.2 不捕获名字且不抛出的 lambda 等价于普通函数，可以转换为函数指针。

6.3 其余 lambda 是闭包值：一个匿名名义类型，字段保存被捕获变量的地址。闭包没有
可写出的类型名，**应**用 `auto` 保存。

6.4 闭包按引用捕获其体内使用的外层局部绑定与形参。

6.5 lambda 的形参类型可以省略；省略时由每次调用推断。

6.6 调用 lambda 字面量**必须**加括号：`(lambda(x int) -> x)(1)`。

6.7 lambda 体可以 `raise`；此时其调用点遵循 [06 异常](07-exceptions.zh.md)。体内
完全捕获的异常不使 lambda 可能抛出。

6.8 闭包保存的是地址，不延长被捕获对象的生命。返回捕获了局部变量的闭包是悬垂
引用，其调用是未定义行为。

## 重载与调用

7.1 同一名字可以有多个重载。调用时由接收者与实参类型选出唯一匹配。

7.2 无法选出唯一匹配时，实现**必须**报告诊断。

7.2.1 选重载**只看参数表**。返回类型不是签名的一部分，从不参与选择，所以两个只有返回值
不同的定义只能靠参数区分——区分不出来时，调用就是歧义的，会被报告：

```ft
fn f(a int) int { return 1; }
fn f(a int) bool { return true; }

fn main() int {
    x int = f(1);
    return 0;
}
```

该程序不符合本规范，报告为：

```text
error[S0037]: the call to `f` is ambiguous: 2 overloads match
```

结果的期望类型不能打破这个平局——读者必须不必看返回值被怎么用，就能说出跑的是哪一个函数。

7.2.2 标了 `@overridable` 的定义是一个**默认实现**：同名的任何其他定义取代它，于是调用处
只有一个候选而不是两个。库用这种方式给出一个兜底实现，程序接管它时调用处什么也不用写。
该属性见 [附录 C §C.3](appendix-c-attributes.zh.md#c3-函数)。

7.3 函数名用于要求函数指针的位置时，由目标函数类型选出重载。

7.4 类型名与函数名不共享命名空间。

## 形参包

8.1 函数的**最后一个**形参可以是包：`values ...Ts` 或 `values ...T`。

8.2 包的元素类型：`...Ts`（类型包）时元素类型为各实参类型；`...T` 时所有元素
同型；`...int` 时每个实参都**必须**是 `int`。

8.3 包后不得再有形参；包形参不得有默认值；带包的调用不接受关键字实参。

8.4 函数体中包只能用于：`sizeof...(values)`、`f(values...)`、
`(语句, ...)`。

8.5 每个调用产生一个独立实例；元素类型与个数参与符号。

8.6 成员函数的包从接收者之后开始消耗实参。

## 返回类型推断

9.1 返回类型写作 `auto` 时，由 `return` 语句推断。

9.2 所有带值的 `return` **必须**给出同一类型。

9.3 所有 `return` 都不带值时返回类型为 `void`。

9.4 推断结果在编译期固定；导出函数的签名包含推断结果，因此可跨模块调用。

## 移动

10.1 值分为有名字的值与将死的值（临时量、调用结果）。

10.2 将死的实参可以绑定到 `&&T` 形参并被移动；有名字的值**不得**自动移动。

10.3 移动之后源处于合法的空状态：指针为空、长度为零；仍可读、赋值与销毁。

10.4 移动与拷贝的选择由类型决定：声明 `__init__(this &T, other &&T)` 的类型有
移动构造，声明 `__assign__(this &T, other &&T)` 的类型有移动赋值。

10.5 没有声明移动操作的类型的按第 4.3.1 条复制。

## 转发引用与 `std.forward`

11.1 模板形参位置的 `&&T` 是转发引用：实参为左值时 `T` 推断为 `&U`，实参为
右值时为 `U`。

11.2 `&&T` 按引用折叠规则处理：仅 `&& &&` 保持右值引用。

11.3 `std.forward<T>(value)` 在 `T` 为引用时给出左值，否则给出右值引用。其行为
由标准库规定。

## 从调用推出模板实参

11.4 模板参数只从实参的类型推出，不从别处推出。写成 `T` 的形参取实参的类型；
写成 `&T`、`&const T` 或 `*T` 的形参取实参所指或所指向的东西。

11.5 不出现在形参类型里的参数不由实参推出。`template <T type, K usize>` 写成
`fn f(a [3]T)` 时，只有调用方写出 `K` 才有值：形参里的长度是声明的常量，不是
关于实参的问题。

11.6 写成 `[N]` 的长度**会**被推出，数字来自实参自身的数组长度：

```ft
import C;

template <T type, N usize>
fn count(a [N]const T) usize {
    return N + (a[0] != '\0') as usize * 0usize;
}

fn main() int except {
    C.printf("%zu\n", count("abc"));
    return 0;
}
```

`N` 是 4，因为 `"abc"` 连同终止符共四个字符——字面量的类型是 `[4]c8`。写出的长度
指明了是哪个参数，实参给出它的值。写出的表达式本身不被求值。该程序输出 `4`。

11.7 正因如此，一处声明能服务所有数组：同一个 `begin` 用于 `[4]c8`、`[3]int` 与
`[1024]f64`，每次调用取各自的长度。

11.8 在某个模块里声明的模板，其实例化与声明在调用方模块里没有分别。实参类型按同
样的方式决定，数组实参的长度在两种情况下都从实参读取。

## 求值顺序

12.1 函数实参从左到右求值。

12.2 逗号运算符从左到右求值；`&&`、`||`、`?:` 短路求值。

12.3 一个实参在绑定到形参之前**只求值一次**，包括需要取其地址的情形。

## 递归与前置引用

13.1 模块层的名字在同一作用域内先全部声明，再检查函数体；函数之间可以相互
调用，与书写顺序无关。

13.2 类型可以经由指针或引用提及后声明的类型（见
[03 声明](03-declarations.zh.md#前置声明)）。
