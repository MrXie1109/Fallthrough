# 10 诊断

> [English](10-diagnostics.md)

## 范围

本篇规定实现所报告诊断的编号、结构、严重级别、分组与抑制机制。诊断文本的具体
措辞不属于规范内容；编号、位置与类别属于规范内容。

## 编号

2.1 每条诊断带一个稳定编号，由阶段字母与四位数字组成。

| 前缀 | 阶段 |
| ---- | ---- |
| `D` | 驱动程序 |
| `L` | 词法与宏展开 |
| `P` | 语法分析 |
| `S` | 语义（名字解析与类型检查） |
| `I` | 内部错误 |

2.2 编号是实现的对外契约：同一错误在不同版本中**必须**使用同一编号；措辞可以
变化。

2.3 `I` 类诊断表示实现未能完成工作，而非程序有错。实现**必须**以 bug 严重级别
报告此类诊断，并指出未能处理的构造。

## 诊断结构

3.1 一条诊断包含：

- 严重级别（error 或 warning）；
- 稳定编号；
- 主位置：以 `^^^` 标出的源文本范围；
- 消息：一句话陈述问题；
- 可选的补充说明（`= note:`）：相关规则或修正方式。

3.2 涉及语言规则的诊断**应当**给出对应规则的补充说明。

3.3 诊断的位置**必须**指向引起问题的源文本范围。

## 严重级别

4.1 `error` 表示程序不符合本规范；实现**必须**拒绝该程序。

4.2 `warning` 表示程序可以编译，但**应**检查其意图。警告不改变退出码，除非实现
以 `-Werror` 等方式被要求将警告视为错误。

4.3 警告可以按组控制。组名是实现接口的一部分。

## 警告组

| 组 | 报告内容 | 编号 |
| -- | -------- | ---- |
| `unused` | 声明后从未被读取的局部变量 | `S0140` |
| `unused-parameter` | 从未被读取的形参（`extern` 函数形参与 trait 类型参数除外） | `S0142` |
| `shadow` | 遮蔽同一函数中外层绑定的局部声明 | `S0143` |
| `constant-condition` | 条件为字面量的 `if`/`while`（`while (true)` 除外） | `S0144` |
| `assignment-in-condition` | 条件位置上的赋值 | `S0145` |
| `self-comparison` | 值与自身比较（trait 要求中的 `it < it` 与浮点 `x != x` 除外） | `S0146` |
| `division-by-zero` | 除数为编译期已知的零 | `S0147` |
| `use-after-move` | 移动后读取该值 | `S0148` |
| `unreachable` | 永远执行不到的语句 | `S0141` |
| `useless-raise-mark` | 挂在不会抛出的调用上的 `?!` | `S0083` |
| `deprecated` | 使用带 `@deprecated` 的声明 | `S0160` |

5.1 实现**必须**提供按组开关警告的方式：

```text
-W<name>        报告该组（默认全部报告）
-Wno-<name>     不报告该组
-Wall           恢复默认：全部报告
-Werror         把报告出来的警告当作错误
```

5.2 组名写错时实现**必须**报告用法错误，并列出可用组名。

5.3 `-Wverbose` **应**在诊断中附带组名与解释；默认输出不附带。

5.4 `-Wno-<name>` 与 `-Werror` 同时使用时，被关闭的组既不报告也不报错。

5.5 以 `_` 开头的名字表示有意不使用；`unused` 与 `unused-parameter` 对其保持
沉默。

5.6 警告**只**针对用户书写的源文件报告；导入库的代码不报告。

5.7 `use-after-move` 的实现是保守的：按同一块内的语句顺序跟踪，嵌套块中的移动
不计入。

5.8 `shadow` **只**考虑同一函数内的名字。

5.9 `constant-condition` 只认字面量。

## 就地抑制

6.1 警告可以在行尾以注释方式就地抑制。只有下列三种形式构成指令：

```ft
x int = 1;                    // no warning
// 说明文字 —— no warning
by_code int = 2;              // no warning: S0140
by_group int = 3;             // no warning: unused
```

6.2 注释内容恰为 `no warning`：抑制该行的全部警告。

6.3 注释以 `-- no warning` 结尾：同上；`--` 之前的文字是说明。

6.4 `no warning: NAME[, NAME]…` 只抑制指定编号或组。

6.5 仅提及 `no warning` 的注释不是指令。

6.6 指令的生效位置：被报告的行、其上方只含注释的行，或诊断覆盖的任意行。

6.7 指令**必须**位于行尾；字符串字面量中的文本不构成指令。

6.8 就地抑制优先于 `-Werror`，且只对警告有效。

## 颜色

7.1 诊断的颜色由实现选项控制：`auto`（默认，仅终端着色）、`always`、`never`。

7.2 环境变量 `NO_COLOR` 被设置时，`auto` 不着色。

7.3 去除转义序列后的诊断文本**必须**与不着色时逐字节相同。

## 去重

8.1 实现**必须**对严重级别、编号、主位置与消息均相同的诊断去重。

8.2 同一模板的多次实例化中出现的同一错误**应**只报告一次。

8.3 位置不同或消息不同的诊断**不得**合并。
