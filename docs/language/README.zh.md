# Fallthrough 语言规范

> [English](README.md)

本中文文本是英文**主文本**的翻译。每个分册的英文主文本名为 `*.md`，中文翻译名为
`*.zh.md`；两者不一致时以英文主文本为准，修正的是翻译而不是英文文本。文档按自身
语言互相链接：英文页面链接 `NN-*.md`，中文页面链接 `NN-*.zh.md`。

## 范围

本文件及其分册构成 Fallthrough 语言的**规范文本**。它规定：

- 一个符合本规范的翻译单元的词法结构、语法结构与静态语义；
- 一个符合本规范的程序在运行时的行为，以及在何种条件下行为不受规定（未定义行为）；
- 实现必须诊断的构造，以及诊断所必须携带的信息类别。

本文件**不规定**：

- 标准库的内容与行为；标准库是实现附带的库，其规范见
  [`../collections.zh.md`](../collections.zh.md)、[`../library.zh.md`](../library.zh.md) 与
  [`../c-bindings.zh.md`](../c-bindings.zh.md)；
- 编译器命令行的具体拼写（其契约见 [00 总则](00-start.zh.md)）；
- 目标平台的 ABI 细节；本规范只要求程序在平台 ABI 允许的范围内保持本文件规定的
  可观察行为。

## 术语和定义

下列术语和定义适用于本文件。

| 术语 | 定义 |
| ---- | ---- |
| 翻译单元 | 一个 `.ft` 源文件连同它静态导入的全部模块所构成的编译单位 |
| 模块 | 由 `.ftm` 文件声明的、可被 `import` 的命名声明集合 |
| 程序 | 一个或多个翻译单元共同链接而成的可执行映像 |
| 绑定 | 由声明引入、具有名字与类型的存储位置 |
| 地方（place） | 可寻址的存储：绑定、字段、下标结果、`*p`、返回引用的调用 |
| 值 | 不属于地方的表达式结果；也称右值 |
| 将死的值 | 其生命在表达式结束后即结束的值：临时量、调用结果 |
| 名义类型 | 由 `type`、`union`、`enum`、`interface`、`traits` 声明引入的类型 |
| 特殊方法 | 以 `__name__` 拼写、由语言在特定构造下调用的成员函数 |
| trait | 一组要求的名字；类型是否满足由实现于编译期回答 |
| 实例化 | 一组模板实参所对应的一份函数或类型 |
| 实现 | 将本规范具体化的编译器及其附带的标准库 |

## 一致性

4.1 一个**符合本规范的程序**必须只使用本文件规定的构造，并且不依赖本文件规定为
未定义的行为。

4.2 一个**符合本规范的实现**必须：

- 接受符合本规范的程序，并产生本文件规定的可观察行为；
- 对违反本规范约束的程序给出诊断，除非本文件明确允许其他行为；
- 以本文件规定的编号类别报告诊断（见 [10 诊断](11-diagnostics.zh.md)）。

4.3 实现可以对程序施加本文件未规定的资源限制（时间、内存、递归深度、模板实例化
次数等）。达到限制时，实现必须给出诊断，不得静默产生违反本规范的结果。

4.4 实现可以在本文件未规定处作出选择，但该选择必须在实现的文档中说明，且不得
改变符合本规范的程序的可观察行为。

## 规范性关键词

本文件使用下列关键词，其含义固定：

- **必须**、**不得**：规范性要求。违反即构成不符合本规范的程序或实现。
- **应**、**不应**：规范性建议。违反不改变程序的含义，但实现应在文档中说明差异。
- **可以**：允许的选择。
- **未定义行为**：本文件不规定其行为；程序不得依赖。
- **未指定行为**：本文件允许实现从若干可能结果中选择其一，但不得产生崩溃或
  违反类型安全的结果。

代码示例一律标注为 `ft`。示例为**资料性**内容，仅用于说明条款；当示例与条款正文
冲突时，以条款正文为准。示例中的 `...` 表示省略，不属于语言。

## 阅读顺序

第一次接触本语言的读者可以按分册顺序阅读；读懂一个程序只需要前三册，写程序则需要其余部分：

1. [00 总则](00-start.zh.md) 与 [01 词法](01-lexical.zh.md)：源文件是什么、如何变成记号；
2. [02 类型](02-types.zh.md) 与 [03 声明](03-declarations.zh.md)：类型系统与名字的引入；
3. [04 函数](04-functions.zh.md)、[05 协程](05-coroutines.zh.md)、[06 语句](06-statements.zh.md)、
   [08 表达式](08-expressions.zh.md)：行为；
4. [06 异常](07-exceptions.zh.md)、[08 模块](09-modules.zh.md)、[09 作用域](10-scopes.zh.md)：较大程序需要的规则；
5. [10 诊断](11-diagnostics.zh.md) 与两个附录：参考表。

## 未定稿条目

本规范未覆盖的条目在 [`../SPEC-STATUS.md`](../SPEC-STATUS.md) 中标注为 *Open*。
实现遇到此类条目时**必须**报告内部错误类诊断（`I0999`），不得猜测语义。内部错误
类诊断表示实现未完成，而非程序不符合本规范。
