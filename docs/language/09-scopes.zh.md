# 09 作用域

> [English](09-scopes.md)

## 范围

本篇规定名字的作用域、遮蔽与重复声明规则，以及绑定的销毁顺序。

## 作用域

2.1 作用域是**块级**的。下列构造各自引入一个作用域：

- 裸块 `{ … }`；
- `if` 的每个分支块与 `else` 块；
- `while`、`for`、范围 `for` 的循环体；
- `for` 语句本身：其初始子句中的绑定属于该 `for`；
- `switch` 本身：各分支共享此作用域；
- `try`、`except`、`else`、`finally` 的每个块；
- 函数体；
- 模块。

2.2 名字在其作用域内可见；离开作用域后不再可见。

2.2.1 出现在需要值的位置上的块，它的值就是块中末条不带 `;` 的表达式；若末条语句带 `;`，
该块给不出值（`void`）。块里的绑定属于块自己，所以这个值可以由外面并不存在的名字算出来：

```ft
import C;
import std;

fn f() int {
    return {
        x int = 2;
        x + 3
    };
}

fn main() int except {
    C.printf("%d\n", f());
    return 0;
}
```

该程序输出 `5`：块就是 `return` 的值，而 `x` 只属于这个块。

2.2.2 语句位置上的裸块 `{ … }` 是语句块而不是值：区别在于它所在的**位置**。

2.3 `switch` 的每个分支不单独引入作用域；需要独立作用域时写裸块。

## 遮蔽与重复声明

3.1 内层作用域中的声明**可以**遮蔽外层同名绑定；离开内层后外层绑定重新可见。

3.2 同一作用域中重复声明同名绑定是错误。

3.3 形参属于函数的最外层作用域；函数体顶层**不得**再声明与形参同名的绑定。

3.4 局部绑定可以遮蔽模块层名字。

3.5 `_` 的重复声明规则见第 4 节。

## `_`

4.1 `_` 是唯一允许在同一作用域重复声明的标识符；每次出现是独立的绑定。

4.2 `_` 可读，不是丢弃值的占位符。

4.3 一个 `_` 绑定的作用域到块结束，或到同作用域中**下一个 `_` 声明**为止。

4.4 每个 `_` 绑定有独立存储，并在其作用域结束时销毁。

4.5 形参可以命名为 `_`，用于忽略对应实参。

## 生命周期与销毁

5.1 绑定的生命周期从其声明完成时开始，到其作用域结束时结束。

5.2 作用域结束（正常结束、`return`、`break`、`continue`、`raise` 离开）时，
该作用域内已构造的绑定**必须**按声明的逆序销毁。

5.3 销毁通过类型的 `__drop__` 或成员的析构进行；规则见
[07 表达式](07-expressions.zh.md#特殊方法)。

5.4 销毁顺序在异常路径与正常路径上相同；`try` 块中抛出的异常在进入 `except`
之前完成该块的销毁。

5.5 临时量在其所在的完整表达式结束时销毁；移动后的对象仍会在作用域结束时销毁
（处于空状态）。

5.6 程序**不得**依赖未规定顺序的多个销毁之间的相对顺序，除非本规范另有规定。

5.7 离开作用域时，该作用域的 `defer` 块（[05 语句 §8](05-statements.zh.md#defer)）先于
该作用域绑定的销毁执行。两者都按声明逆序，且内层作用域的 `defer` 先于外层作用域的
任何动作。
