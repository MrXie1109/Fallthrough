# 07 表达式

> [English](07-expressions.md)

## 范围

本篇规定表达式的形式与求值：名字、字段、下标、调用、转换、运算符、赋值，以及
由这些构造调用的特殊方法。

## 基本形式

| 形式 | 语义 |
| ---- | ---- |
| `name` | 绑定、常量或模块成员的名字 |
| `a.b` | 字段访问，或模块成员访问（由名字解析决定） |
| `p->b` | 等价于 `(*p).b`；左侧**必须**是指针或可经 `__pointer__` 到达指针 |
| `a[i]` | 下标；语义由类型或内建规则规定 |
| `f(a, b)` | 调用 |
| `obj.m(a)` | 成员函数调用，接收者为第一个实参 |
| `p(1)` | 通过函数指针调用，不写解引用 |
| `f<int>(a)` | 显式模板实参的调用 |
| `T(args)` | 构造调用 |
| `f"…{e}…"` | 插值字符串；展开为对 `std.format` 的调用，见下 |

### 插值字符串

2.1.1 插值字符串 `f"…"` 表示 `std.format(fmt, e1, e2, …)`：`fmt` 是字面量文本，其中每个
占位符替换为 `{}`；`e1…` 是按书写顺序排列的占位符表达式。整个表达式的类型就是 `format`
返回的类型，即标准字符串。

```ft
import std;

fn main() int except {
    n int = 42;
    std.print("{}\n", f"n is {n}")??;    // std.format("n is {}", n)
    std.print("{}\n", f"{n:#x}")??;      // std.format("{:#x}", n)
    return 0;
}
```

该程序依次输出 `n is 42` 与 `0x2a`。

2.1.2 占位符写作 `{表达式}` 或 `{表达式:说明符}`。`说明符` 就是普通的格式说明符：
`{:>8}`、`{:08}`、`{:.2f}`、`{:#x}` 以及转换 `{!s}`/`{!r}` 的行为与手写格式串完全一致，
因为它本来就变成了手写格式串。

2.1.3 `{{` 与 `}}` 是一个字面大括号，因此 `f"{{x}}"` 得到 `{x}` 而不是占位符。

2.1.4 该调用可能抛出，所以插值字符串和其他调用点一样：需要 `try`、`??` 或 `!!`
（[06 异常](06-exceptions.zh.md#求值点义务)）。字面量本身不携带标记——失败往哪里去是程序的
选择，写在使用处。

2.1.5 每个占位符都是一个完整表达式，从左到右各求值一次。其结果由该值的 `__format__`
渲染，没有时由 `str` 渲染（[§8](#特殊方法)）。

2.1.6 `std.format` 来自标准库，因此写了插值字符串的文件**必须**导入它（`import std;` 或
`import std.fmt;`）。没有该导入时，`format` 这个名字解析不到任何东西，程序会像对待其他
未知名字一样被拒绝。

## 转换## 转换

### `as`

3.1.1 类型转换**必须**显式写出：`expr as T`。

3.1.2 合法的转换：

| 从 | 到 |
| -- | -- |
| 任意数值类型 | 任意数值类型 |
| `byte` | 任意数值类型，及反向 |
| 指针或引用 | 同形状的指针或引用 |
| 指向 `byte` 的指针 | 指向任意类型的指针，及反向 |
| `bool` | 任意整数类型（`true` 为 1，`false` 为 0） |

3.1.3 有损数值转换按目标宽度回绕；这是转换的语义，不是错误。

3.1.4 增加 `const` 不需要 `as`；减少 `const` **必须**写 `as`。

3.1.5 名义类型可以声明 `__as__` 定义转换，见第 8 节。

## `sizeof` 与 `alignof`

4.1 `sizeof(T)`、`alignof(T)` 的结果是 `usize` 常量，操作数**必须**是类型。

4.2 `sizeof...(pack)` 是参数包元素个数，不是字节数。

4.3 `sizeof`/`alignof` 可以出现在要求编译期常量的位置。

4.4 函数类型的宽度与指针相同：`sizeof(fn(int) int)` 就是一个地址的大小，因为函数值就是一
个地址。数组量的是它的**元素**，所以 `sizeof([4]int)` 是四个 `int`，而不是指向它们的指针。

```ft
import C;
import std;

fn f(x int) int { return x; }

fn main() int except {
    C.printf("%zu %zu %zu %zu\n", sizeof(int) as usize, sizeof(*int) as usize,
        sizeof([4]int) as usize, sizeof(fn(int) int) as usize);
    return 0;
}
```

该程序在 64 位机器上输出 `4 8 16 8`：`int` 四字节，指针八字节，四个 `int` 的数组十六
字节，函数类型是一个地址。

4.5 操作数可以是类型参数：在 `template <T type>` 里，`sizeof(T)` 就是实例化所给类型的大小。
对大小尚未确定的类型——不完整类型——取 `sizeof` 是错误。

## 运算符

### 条件运算符与逗号

5.1.1 `cond ? a : b` 只求值被选中的分支。

5.1.2 `a, b` 从左到右求值，结果为 `b`。

### 一元与自增自减

| 形式 | 语义 |
| ---- | ---- |
| `-x`、`+x`、`!x`、`~x` | 取负、取正、逻辑非、按位取反 |
| `&x` | 取地址，结果 `*T`；操作数**必须**是地方 |
| `*p` | 解引用，结果 `&T`；操作数**必须**是指针 |
| `++x`、`x++` | 自增；后缀结果为自增前的副本 |
| `--x`、`x--` | 自减 |

5.2.1 `++`/`--` 的操作数**必须**是地方。对名义类型，操作落到 `__inc__`/`__dec__`。

5.2.2 函数名是取地址的例外：`&f` 与裸 `f` 都产生函数指针。

### 赋值

5.3.1 `a = b` 右结合；目标**必须**是地方。

5.3.2 复合赋值包括 `+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`、
`**=`。

5.3.3 对名义类型，`=` 调用 `__assign__`；复合赋值优先调用 `__iadd__` 一类方法，
不存在时等价于 `a = a op b`。

5.3.4 目标类型为引用时，赋值穿过引用写入被引用的存储。

## 求值顺序与未定义行为

6.1 实参从左到右求值；逗号运算符从左到右；`&&`、`||`、`?:` 短路。

6.2 同一实参只求值一次。

6.3 在同一个完整表达式内，对一个值的两次修改之间没有顺序规定时，行为是未定义
行为。

6.4 指针越界访问、解引用空指针、读取联合体非活动成员、整数溢出（`--release`
模式）是未定义行为。

## 编译期查询

7.1 下列表达式在编译期求值，可以出现在要求常量的位置：

```text
sizeof(T)
alignof(T)
sizeof...(pack)
except(expr)
TraitName(TypeArgs…)
@meta.defined(name)
@meta.compilable(name)
```

7.2 `except(expr)` 只分析表达式是否可能抛出，不求值。

7.3 trait 查询与内建类型特征的规则见 [03 声明](03-declarations.zh.md#traits)。

### 本次构建是否有某个名字

7.4 `@meta.defined(name)` 询问 `name` 在本次构建中是否指称任何东西：已导入的模块、
已声明或导入的类型与类型族、本模块的函数与常量、语言自带而无需声明的类型（`int`、
`bool`、`String`），以及平台名。结果类型为 `bool`。

7.5 `@meta.compilable(name)` 回答同一个问题，是含义为“这样写能不能编译”时读起来更
顺的写法。两者由同一份代码回答，因此 `@meta.defined(X)` 与 `@meta.compilable(X)`
永不相互矛盾。

7.6 平台名是 `linux`、`windows`、`macos`、`unix`。对一次给定构建，前三个中恰有一个
成立；`unix` 在 Linux 和 macOS 上成立。

7.7 `@meta.NAME` 与 `@__builtin_NAME` 是同一个问题：`@meta.defined` 与
`@__builtin_defined` 可互换，`compilable` 同理。

```ft
import std;

fn main() int except {
    std.print("{} {}\n", sizeof(int), alignof(int))??;
    std.print("{} {}\n", @meta.defined(linux), @meta.defined(no_such_type))??;
    std.print("{} {}\n", @meta.compilable(int), @meta.compilable(no_such_type))??;
    std.print("{} {}\n", @__builtin_defined(String), @__builtin_compilable(bool))??;
    return 0;
}
```

该程序依次输出 `4 4`、`true false`、`true false`、`true true`。

7.8 查询只接受单个标识符，不接受类型表达式。它在编译期即为常量，因此可以作
`if (cond) @constexpr` 与 `@enable_if` 的条件，这正是让程序只在能编译它的构建中
保留某个分支的手段：

```ft
import std;

if (@meta.defined(linux)) @constexpr {
    fn build_kind() int { return 1; }
} else {
    fn build_kind() int { return 2; }
}

fn main() int except {
    std.print("{}\n", build_kind())??;
    return 0;
}
```

7.9 `@meta.compilable(T)` 回答的是名字 `T` 是否存在，而不是由它构成的任意表达式是否
能编译。要问一个块能否编译，用 `if (auto) @constexpr`，见
[05 语句](05-statements.zh.md)。

## 特殊方法

### 调用表

语言在固定构造上调用固定名字的成员函数。下表是全部可扩展点。

| 特殊方法 | 调用时机 |
| -------- | -------- |
| `__init__` | 值被**显式**构造：`T(args)` |
| `__im_init__` | 值被构造，且允许在目标类型位置隐式完成 |
| `__assign__` | 对已存在的值赋值 |
| `__drop__` | 值的作用域结束或被覆盖 |
| `__getitem__` | `t[i]` |
| `__setitem__` | 显式下标赋值 |
| `__add__`、`__sub__`、`__mul__`、`__div__`、`__mod__`、`__pow__` | 对应二元运算符 |
| `__and__`、`__or__`、`__xor__`、`__shl__`、`__shr__` | 按位运算符 |
| `__neg__`、`__pos__`、`__not__` | 对应一元运算符 |
| `__iadd__` 等 | 复合赋值；未声明时退化为 `a = a op b` |
| `__eq__`、`__ne__`、`__lt__`、`__le__`、`__gt__`、`__ge__` | 比较运算符 |
| `__cmp__` | `a <=> b` |
| `__inc__`、`__dec__` | `++a`/`--a` 及后缀形式 |
| `__deref__` | `*a`：返回引用 |
| `__pointer__` | `a->field` |
| `__call__` | `a(args)` |
| `__bool__` | 条件中的 `a` |
| `__as__` | 显式转换 `x as Target` |
| `__im_as__` | 转换，且允许在目标类型位置隐式完成 |
| `__str__`、`__repr__` | `str(x)`、`repr(x)` |
| `__format__` | 标准库格式化 |

### 内建三件套

8.2.1 基本类型具有内建的 `__init__`、`__assign__`、`__drop__`：`__init__` 为一次
存储，`__assign__` 为一次存储，`__drop__` 无操作。

8.2.2 拥有堆资源的类型**应**声明这三个方法；未声明时实现按成员复制，资源语义由
程序负责。

### `str` 与 `repr`

8.3.1 `str(x)` 与 `repr(x)` 是内建函数，结果是标准库字符串类型。

8.3.2 类型声明了 `__str__`/`__repr__` 时，内建函数**必须**调用它。

8.3.3 操作数为引用时按被引用值渲染。

8.3.4 未声明时按标准库规定的默认规则渲染；不能渲染的类型**必须**报告诊断。

### 运算符与比较

8.4.1 两操作数类型不同或为名义类型时，运算落到左操作数的特殊方法；不存在时尝试
右操作数的反射形式（`__radd__` 等）。

8.4.2 标量比较是内建的；不同宽度的数值按数学值比较。

8.4.3 两个相同的名义类型**不得**自动比较或逐成员比较；需要比较时**必须**声明
`__eq__` 等方法。

8.4.4 比较方法的返回类型由方法决定；用作条件时**应**为 `bool`。

### `__as__`

8.5.1 `__as__` 的第二个形参是**选择器**：指向目标类型的指针，用于选择目标类型，
从不使用。

8.5.2 转换不能靠返回类型区分重载，因此目标类型**必须**写在选择器中。

8.5.3 比较选择器时忽略 `const`。

### 隐式初始化与隐式转换

8.6.1 `__init__` 只用于**显式**构造形式 `T(args)`。当源值不是目标类型时，仅声明
`__init__` 不使初始化、赋值、实参、返回值或字段初始化隐式成立。

8.6.2 `__im_init__` 与 `__init__` 的形式相同，但它同时使该构造可用于**目标类型
位置**的隐式初始化。显式的 `T(args)` 也可以选择 `__im_init__`。

8.6.3 `__as__` 只用于显式转换 `expr as T`。`__im_as__` 与 `__as__` 的形式相同
（定义在源类型上，第二个形参为指向目标类型的选择器），并额外允许源值在目标类型
位置被隐式转换。显式的 `expr as T` 也可以选择 `__im_as__`。

8.6.4 目标类型位置的隐式转换按下列顺序选择，且每步都必须得到唯一候选：

1. 第 12 节列出的内建隐式调整与整数提升；
2. 目标类型的 `__im_init__`；
3. 源类型的 `__im_as__`。

无候选或候选不唯一时，实现**必须**报告诊断。

8.6.5 隐式完成构造或转换可能抛出时，调用点的义务与显式调用相同，见
[06 异常](06-exceptions.zh.md)。

### 可见性

8.7.1 跨模块使用时，特殊方法**必须**一并 `export`。

8.7.2 缺少 `__drop__` 不产生诊断；使用方按无析构处理。
